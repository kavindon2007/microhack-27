## 🎯 The 3 Official Problem Statement Tracks

1. **Industry 5.0 & Smart Manufacturing**
   - *Focus:* Edge AI, Autonomous Industrial Robotics, Predictive Maintenance, Digital Twins, TinyML vibration/acoustic FFT anomaly detection.
   - *Target Hardware:* Microchip SAM E54, PIC32MZ EF, PolarFire SoC FPGA, FreeRTOS, Modbus/MQTT.
2. **Automotive Embedded Systems**
   - *Focus:* AUTOSAR architecture, CAN FD / LIN in-vehicle networking, Smart EV Battery Management Systems (BMS), ADAS radar/vision edge sensor fusion.
   - *Target Hardware:* Microchip dsPIC33 DSCs, ATA6561 CAN Transceivers, MPLAB X IDE, Embedded C/C++.
3. **Medical Imaging & Intelligent Healthcare Systems**
   - *Focus:* Point-of-care ultrasound diagnostic edge processing, wearable vital signs patch (ECG, PPG, SpO2), continuous telemetry, ultra-low power biosensors.
   - *Target Hardware:* Microchip SAM L22 (Ultra-Low Power), PIC32, Precision Analog Front-Ends (AFE), BLE 5.2.

## ⚡ Architecture & Features Built

- **DedSec / Cyber-Industrial Glass Aesthetics**: Custom Tailwind CSS design system with Space Grotesk typography, glowing circuit orbs, CRT ambient grids, and dynamic cursor sheen tracking mouse coordinates.
- **Dynamic Client-Side Routing**: SPA architecture supporting `/`, `/guidelines`, `/challenges`, `/challenges/:id`, `/schedule`, `/register`, `/submit`, `/my-submissions`, `/health`, `/privacy`, and `/terms`.
- **Interactive Flyer QR Scanner Modal**: Direct pop-up viewer displaying the official registration QR code matching the poster with 1-click download.
- **Live 36-Hour Hackathon Countdown**: Real-time ticker counting down to 25 February 2027.
- **Team Registration Portal**: Full multi-member (2 to 4 students) registration form with validation and instant localStorage draft saving.
- **Proposal Submission Engine**: Round 1 PPT / PDF submission with Google Drive validation.
- **Production Vercel Ready**: Pre-configured `vercel.json` with SPA catch-all rewrites and security headers.
